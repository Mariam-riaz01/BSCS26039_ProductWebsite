# BSCS26039_ProductWebsite
Quill & Co.is a stationery product site built with HTML, CSS, and JavaScript_ no frameworks, no build tools, just plain HTML, CSS and JavaScript.
Features : Responsive navbar with hover effects shared across all pages. Full width hero banner and a promotional "Explore our product" section. Five products each with an image, price, and description. Check Availability button per product reveals IN stock/Out of stock only after its clicked. Order Now button per product opens a shared popup asking for name and email, validates the fields and confirms the order.
